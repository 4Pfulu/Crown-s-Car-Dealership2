## Project Overview
Crown's Car Dealership is a fictional small, independently owned car dealership based in Pretoria, Gauteng, specialising in new and pre-owned vehicles. This project is part of a three-part Portfolio of Evidence for WEDE5020, in which a fully functional, responsive, and SEO-optimised website is developed for the dealership. This part of the submission focuses on the visual design and responsive behaviour of the website using CSS.

## Website Goals and Objectives
- Establish a professional online presence for Crown's Car Dealership.
- Allow potential customers to browse available vehicle stock online.
- Generate qualified sales leads through an online enquiry form.
- Provide clear, accessible information on services, financing, and contact details.

## Key Features and Functionality
- Responsive navigation menu linking all pages.
- Homepage with hero section and featured vehicles.
- Vehicle listings page (Products).
- Enquiry form for product and finance enquiries.
- Contact page with two branch locations and a general contact form.
- External CSS stylesheet applying consistent typography, colour scheme, and layout across all pages.
- Fully responsive design tested across desktop, tablet, and mobile screen sizes.

## Timeline and Milestones
- **Week 1:** External stylesheet created and linked to all pages; base styles, typography, and layout (CSS Grid/Flexbox) applied.
- **Week 2:** Visual styling, interactive states, responsive breakpoints, responsive images, and cross-device testing completed.

## Part 2 Details
Part 2 focuses on the visual design and responsive behaviour of the website. An external CSS stylesheet was created and linked to all five pages, applying consistent typography, colour scheme, and layout using CSS Grid and Flexbox. Interactive states (`:hover`, `:focus`, `:active`) were added to navigation links, buttons, and form fields. The site was made fully responsive using relative units, media query breakpoints (900px and 600px), and `<picture>`/`srcset` for responsive vehicle images.
